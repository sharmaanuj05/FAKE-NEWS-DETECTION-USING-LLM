System Architecture

8GB Laptop Optimization Profile

How this project executes transformer inference and fine-tuning seamlessly on a standard 8GB RAM laptop without memory crashes.

1. DistilBERT vs BERT-Base Efficiency

Standard 70B and 8B LLMs require 16GB-32GB VRAM. By utilizing DistilBERT (66 million parameters) instead of heavyweight models:

  • Memory Footprint: Only ~260MB model size (fits comfortably inside 8GB RAM alongside macOS/Linux OS).
  • Speedup: 60% faster inference than BERT-base while retaining 97% of BERT's language understanding capability.
  • MPS / CUDA Auto-Offloading: Automatically offloads tensor operations to Apple Silicon MPS or NVIDIA CUDA if available, falling back gracefully to optimized multi-threaded CPU.

2. Fine-Tuning Execution Pipeline

To fine-tune the classifier on your custom dataset on an 8GB machine, execute:

# Activate virtual environment source .venv/bin/activate # Run fine-tuning with memory-safe batch size (4) and gradient accumulation python src/train.py --epochs 3 --batch-size 4 --model distilbert-base-uncased

Saved checkpoints are automatically placed into models/fine_tuned_bert/.

3. Cache Evacuation & Memory Bounds

After each inference batch, torch.mps.empty_cache() or torch.cuda.empty_cache() is called to prevent memory leaks and keep system RAM under the 2GB safe ceiling.

Integration & Cross-Industry Tooling

REST API Documentation

Programmatic access for education platforms, media literacy courses, newsroom publishing workflows, and compliance pipelines.

POST /api/analyze

Analyze raw text and return veracity predictions, 4-pillar scores, token saliency, and reasoning explanations.

curl -X POST "http://localhost:8000/api/analyze" \ -H "Content-Type: application/json" \ -d '{ "title": "Phase 3 clinical trial demonstrates...", "text": "A randomized, double-blind trial published in NEJM...", "include_saliency": true }'

GET /api/evaluate

Returns quantitative accuracy, precision, recall, F1, and confusion matrix against benchmark dataset.

curl -X GET "http://localhost:8000/api/evaluate"
